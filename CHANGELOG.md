# Historial de versiones

## v1.1.0 — 2026-11-17

- Se agrega el registro de productos al menú de la aplicación.
- Se validan código único, nombre obligatorio, precio no negativo y existencia
  no negativa.
- Se incorporan 7 pruebas unitarias del registro (14 en total).
- Se documenta el procedimiento de despliegue, la automatización con GitHub
  Actions y el rollback.

## v1.0.0 — 2026-11-17

- Primera versión del Sistema de Inventario.
- Consulta del inventario de libros y búsqueda por código o por nombre.
